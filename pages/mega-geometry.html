Mega Geometry test

Features wgpu-partitioned-acceleration-structure and wgpu-cluster-acceleration-structure (Vulkan, NVIDIA RTX Mega Geometry). Every build reads GPU-style argument arrays that refer to buffers and BLASes by device address. Top strip: a partitioned TLAS with four instances of an ordinary quad BLAS in two partitions. Middle strip: the same TLAS updated in place, rewriting instance 3 with a new position and ID. Bottom strip: four triangle clusters built from vertex data, a BLAS built from those clusters, and a partitioned TLAS with two instances of it; the BLAS address the GPU wrote is copied into the instance records. Ray queries write 1 + 16 × instance ID + primitive index per pixel, compared with the CPU's answer away from edges. Results are also printed as MEGA ... lines.
