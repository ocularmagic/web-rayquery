Cooperative vector test

Feature wgpu-cooperative-vector (Vulkan, NVIDIA): each invocation runs a small neural-network layer, y = W·x + b with a 16×16 f16 matrix from a storage buffer, through WGSL coopVecMatMulAdd (and coopVecMatMul reading the matrix column-major, so Wᵀ·x). Small integers keep every value exact in f16, so the results must equal the CPU's. Results are also printed as COOPVEC ... lines.
