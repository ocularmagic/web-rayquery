Opacity micromap test

Feature wgpu-opacity-micromap (Vulkan). Three instances of a non-opaque quad, traced with ray queries that accept every candidate hit. Left: no micromap, so both triangles are hit. Middle: a 2-state micromap marks triangle 0 transparent and triangle 1 opaque, so only triangle 1 is hit, without a candidate. Right: the same BLAS with the DISABLE_OPACITY_MICROMAPS instance flag, so both are hit again. Results are also printed as OMM ... lines.
